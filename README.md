# 🎓 LearnHub – MERN Stack Learning Management System

A full-stack Learning Management System built with **MongoDB, Express, React, and Node.js**.
Students can browse and enroll in courses, instructors can create/manage courses, and admins can oversee the platform.

---

## ✨ Features

- 🔐 JWT-based authentication (Bcrypt password hashing)
- 👥 Role-based access: **Admin**, **Instructor**, **Student**
- 📚 Course CRUD (create, read, update, delete)
- 🎯 Course enrollment with progress tracking
- 🛡️ Protected frontend routes & backend middleware
- 🎨 Clean UI with React Bootstrap
- ⚡ REST API built with Express
- 🗄️ MongoDB + Mongoose for data persistence
